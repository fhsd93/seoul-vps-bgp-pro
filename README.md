## 原生 IP、住宅 IP，和那个没有统一标准的“纯净度”

原生 IP 指 IP 的注册运营商与服务器实际所在地一致。住宅 IP 是 ISP 分配给家庭用户的地址，在某些平台眼里更接近真实用户。

被问得最多的“IP 欺诈值”“纯净度评分”，第三方检测站并没有统一的评分依据，IP 也没有干净、老旧这种分级。TikTok 这类平台有自己的 IP 库和判定方式，一个检测站给 0 分，不等于目标平台也这么判。

所以卖家写“可解锁 Netflix 韩区”“可解锁 ChatGPT”，只能说明他那次测试通过了。流媒体和 AI 平台的风控策略随时调整，拿到 IP 自己跑一遍才算数。AkileCloud 首尔三档都给 1 个韩国原生 IPv4、不带 IPv6，业务依赖 IPv6 出口的话这点要先确认。
